# Sunloop replay pass

Two goals use the existing level: Sun sprint (Sun only) and One more thing (Sun plus music). Each completed escape compares against its own haul category. First finish sets a time; later finishes report improvement, tie, or time behind. Failed escapes never set a time. The next-goal message encourages the other haul before suggesting time improvement.

Times use simulation ticks at 120 Hz. Bests live only in the mounted controller and survive retries, not page reloads or navigation. Compact and depot routes have independent visits. No personal records, keepsakes, guild results or tournament attempts are written. This deliberately preserves the playtest boundary until level design is stable.

The menu shows both goals and session bests. No extra gameplay controls, speed cutoffs, currency or rewards were added. The existing illustrated artwork and movement simulation are unchanged.

Validation: 137 tests, including consecutive actual-controller depot escapes with different hauls, category comparisons, duplicate results, and failure rejection. Physical-phone visual and fun validation remains outstanding.

Playtest question: after the first escape, does the other haul or beating your time make you want another attempt? If neither does, revisit route decisions before adding progression rewards.
